STUDENT PREDICTION EXERCISES 1-3
=================================

Files:
- train_model.py: trains and saves the model.
- predict_student.py: loads the saved model and makes three predictions.
- app.py: Exercise 2 Flask API.
- streamlit_app.py: Exercise 3 Streamlit interface.
- requirements.txt: required Python packages.
- student_pass_model.joblib: generated when train_model.py runs.

HOW TO RUN IN VS CODE (Windows PowerShell)
------------------------------------------

1. Open this folder in VS Code.
2. In Terminal > New Terminal, install dependencies:

   python -m pip install -r requirements.txt

3. Train and save the model (run this first):

   python train_model.py

4. Exercise 1 - run three predictions:

   python predict_student.py

5. Exercise 2 - start the Flask API:

   python app.py

   Keep that terminal open. Open a second terminal and test:

   $body = @{ study_hours = 5; attendance_percentage = 90 } | ConvertTo-Json
   Invoke-RestMethod -Uri "http://127.0.0.1:5000/predict" -Method Post -ContentType "application/json" -Body $body

   To test invalid attendance:

   $body = @{ study_hours = 5; attendance_percentage = 120 } | ConvertTo-Json
   Invoke-RestMethod -Uri "http://127.0.0.1:5000/predict" -Method Post -ContentType "application/json" -Body $body

6. Exercise 3 - start Streamlit (stop Flask with Ctrl+C first if using the same terminal):

   python -m streamlit run streamlit_app.py

   Open the Local URL shown in the terminal, usually http://localhost:8501.

IMPORTANT:
- The model file student_pass_model.joblib is generated by train_model.py.
- Run train_model.py before running predict_student.py, app.py, or streamlit_app.py.
- This sample model uses study hours only. Attendance is validated and returned by the Flask API, but does not affect predictions.
- The training dataset is illustrative, not real student data.
